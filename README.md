## ⭐ Featured

### [A Calmer News](https://github.com/sean6369/newsapp) · [Live](https://news.seanlsk.com)
A self-hosted news archive for one reader. Every hour it pulls a handful of feeds, clips the full text of each story, scores it against my interests, and groups outlets that covered the same event. Everything lives in one Postgres table with both a full-text and a vector index. Each page queries it a different way: a daily feed, typo-tolerant search, a clipping library, and an Ask page where an LLM answers from the archive using hybrid retrieval and cites the articles it used.

### [homelab](https://github.com/sean6369/homelab)
Configuration for a two-machine homelab: a home server that runs the services, and an Oracle Cloud instance that only holds the backups and monitors the home server from outside. Rebuilt after an SSD failure in August 2026 around one rule: backups and external monitoring are built and restore-tested before the services they protect come back. Docker Compose stacks with SOPS-encrypted secrets, Borg backups, and Uptime Kuma, connected over Tailscale.

### [PSA L2 Ops AI Co-Pilot](https://github.com/Path-yang/PSA-Code-Sprint-25) · [Live](https://psa-code-sprint-25-frontend.vercel.app/)
*🏆 3rd Runner-up (of 400+ teams) @PSA Code Sprint 2025*  
An AI diagnostic assistant with ticketing for Level 2 product operations. It parses incoming alerts, searches application logs, knowledge-base articles, and past cases, then proposes a root cause and resolution steps.
